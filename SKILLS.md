# Skills demonstrated in this repo

> *A human-readable index of the reusable build and geometry methods documented in the ashiko workshop repository.*

## Stave construction

- **[stave-construction-compound-miter](skills/stave-construction-compound-miter.md)** *(canonical: this repo)* — turn a target shell diameter and stave count into cuttable stave geometry and a repeatable table-saw setup.

## Cross-repo links

- [`djembe`](https://github.com/tonykoop/djembe) grows out of the same family of stave-construction problems, but with a more complicated goblet profile.
- [`dundun`](https://github.com/tonykoop/dundun) simplifies the same method down to a constant-angle cylindrical case.
- [`chessboard-table`](https://github.com/tonykoop/chessboard-table) is a furniture-scale example of the same segmented glue-up discipline in a flat panel instead of a drum shell.
